# 🚗 Car Rental Website

A modern car rental website built using HTML, Tailwind CSS, DaisyUI, and Swiper.js.

This project focuses on translating a complete desktop Figma design into a clean, modern, and user-friendly car rental website.

**Project Status:** In Progress

The project is currently under active development. All website pages and the responsive mobile version are being implemented.

The desktop version follows the provided Figma design, while the mobile responsive version is designed and implemented independently.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern UI based on Figma design
- Multiple website pages currently under development
- Car search and rental interface
- Date and time selection
- Pickup location selection
- Interactive hover effects and smooth interactions
- Interactive sliders using Swiper.js
